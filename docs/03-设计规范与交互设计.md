# 设计规范与交互设计（以 DeepSeek 风格为基础）

> 文档版本：v0.1 · 2026-11-05
> 依据 DeepSeek 官网实测 design token（oh-my-design.kr，82 个 `--ds-*` 变量）与 chat 端拆解推导。标注 ✅ = DeepSeek 实测继承，🔶 = 本产品适配推导。

---

## 1. 设计立场

**「克制的工具感」**：面向研发的 S3 客户端本质是高频、高信息密度的操作台，而 DeepSeek 风格的核心是低装饰、透明度分层、近黑动作色、品牌蓝仅做强调。两者结合的原则：

1. 继承 DeepSeek 的**色彩、圆角、边框、阴影、动效克制**；
2. 信息密度适度上调（研发工具需要表格、路径、多列），但层级仍靠**透明度与边框**而非彩色填充；
3. 品牌蓝 `#4D6BFE` 只出现在：当前集群标识、选中态、链接、焦点环——**绝不大面积铺蓝**；
4. 主按钮近黑 `#1A1615`，危险按钮保持语义红但同样低饱和。

## 2. 色彩系统（Design Token）

```css
:root {
  /* 品牌 ✅ */
  --ds-color-brand: #4D6BFE;
  --ds-color-brand-deep: #3A65C2;
  --ds-color-brand-medium: #4176E6;
  --ds-brand-wash: rgba(65,118,230,.12);   /* 选中态洗底 ✅ */

  /* 动作 ✅：主按钮近黑，非品牌蓝 */
  --ds-btn-primary-bg: #1A1615;
  --ds-btn-primary-fg: #FFFFFF;

  /* 前景 ✅：黑 + 透明度分级，而非灰阶 */
  --ds-fg: #1E232C;
  --ds-fg-2: rgba(30,35,44,.70);
  --ds-fg-3: rgba(30,35,44,.55);
  --ds-placeholder: #8691A1;
  --ds-link: #234792;

  /* 背景 ✅：暖白画布，浮层纯白 */
  --ds-bg-page: #F9F8F8;
  --ds-bg-surface: #FFFFFF;
  --ds-bg-glass: hsla(0,0%,100%,.45);       /* 玻璃面板 ✅ */

  /* 边框四档 ✅：全部黑降透明 */
  --ds-border-subtle:  rgba(0,0,0,.06);
  --ds-border-divider: rgba(0,0,0,.08);
  --ds-border:         rgba(0,0,0,.10);
  --ds-border-strong:  rgba(0,0,0,.20);
  --ds-border-glass:   rgba(9,45,78,.14);   /* 玻璃卡描边 ✅ */

  /* 阴影 ✅：唯一 token */
  --ds-shadow-card: 0 0 1px #F1F5F9, 0 2px 4px rgba(0,0,0,.05), 0 12px 24px rgba(0,0,0,.06);

  /* 语义色 🔶：低饱和适配 */
  --ds-success: #2E7D5B;  --ds-success-wash: rgba(46,125,91,.10);
  --ds-warning: #B4762A;  --ds-warning-wash: rgba(180,118,42,.10);
  --ds-danger:  #C2453D;  --ds-danger-wash:  rgba(194,69,61,.10);

  /* 多集群标识色 🔶（本产品扩展） */
  --cluster-red: #C2453D; --cluster-green: #2E7D5B;
  --cluster-blue: #4176E6; --cluster-purple: #7A5AF8; --cluster-amber: #B4762A;
}
```

**深色模式 🔶**：低饱和深灰（`#1F1F1F` 画布 / `#292A2A` 表面），文字反转为白降透明度，边框改为白降透明（.08/.12/.16/.25），品牌蓝提亮至 `#6C86FF`；不使用纯黑。

## 3. 排版 ✅

- `--ds-font-sans: "DM Sans", system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`（拉丁用 DM Sans，中文回退系统黑体）；
- `--ds-font-mono: ui-monospace, "SF Mono", "JetBrains Mono", Consolas, monospace`——**研发特化：key、ETag、endpoint、错误码一律 mono**；
- 字级：正文/控件 15px·500（表格正文 13px·400），次要 13px·500（chip），小注 12px·400；行高 1.6；字重只用 400/500 两档，无 bold。

## 4. 形状与间距 ✅

- 圆角六档：`sm 8 / input 10 / media 12 / panel 16 / card 24 / pill 100`（px）。按钮 8，输入框 10，对话框/浮层 16，空状态卡 24，chip/胶囊 100。
- 间距双峰：组件内 4·8·12·16·24；区块间 32·40·56；页面留白 80+。研发工具取偏紧凑一侧：列表行高 36px，表格行 32px。
- 分层靠「半透明白表面 + 12px backdrop-blur + 藏青玻璃边」，弹层悬浮时启用；静止卡片用纯白 + 唯一阴影 token。

## 5. 组件规范

| 组件 | 规范 |
| --- | --- |
| 主按钮 | 近黑实心、白字、8px 圆角、32px 高（大 CTA 44px 胶囊）；hover 提亮而非加深 ✅ |
| 次按钮 | 40% 白半透明 + rgba(9,45,78,.18) 边、胶囊、44px 高；hover 边框加深至 #092D4E ✅ |
| Ghost 按钮 | 透明底，hover 4% 黑洗底；表格行内操作用此变体 ✅ |
| 选中态 | 品牌 wash 洗底（rgba(65,118,230,.12)）+ #4176E6 文字 + 浅蓝边 ✅——用于当前集群、当前目录、激活 tab |
| 输入框 | 10px 圆角、1px `--ds-border`、focus 时 2px 品牌蓝环（**超越原作的补强**，DeepSeek 官网未自定义 focus ring） |
| Chip | 18px 圆角（视觉全圆）、34px 高、13px·500；存储类、集群 tag、传输状态均用 chip |
| 对话框 | 16px 圆角白卡 + 唯一阴影 token；危险操作对话框标题用 `--ds-danger`，正文必须完整显示「集群名 + 桶 + 对象数」 |
| Toast | 右下角玻璃卡（blur + 玻璃边），错误 toast 附 RequestId 与「复制」ghost 按钮 |
| 表格 🔶 | 无斑马纹；1px divider 行分隔；hover 4% 黑洗；数字/大小右对齐 mono；列排序 ghost 图标 |
| 空状态 | 空白画布 + 居中白卡（继承 chat 端「Centered card on a blank canvas」），一个主 CTA |

## 6. 图标与动效 ✅

- 线性图标，1.5px stroke（推荐 Lucide），20px 网格；无填充图标、无彩色插画。
- 动效 150–250ms、ease-out；仅用于：hover 边框/洗底、侧栏折叠、进度条、流式日志滚动。无弹跳、无视差。
- 长任务（传输、能力探测）：进度条 + 可展开的**流式日志灰字区**（12–13px 灰色 mono，完成后折叠为一行摘要「已完成 · 42 个对象」）——直接继承 DeepSeek「深度思考」折叠区的交互隐喻，非常契合研发审美。
- 上传/下载进行中的对象行：文件名后内联 chip「上传中 63%」，暂停/恢复用 ghost 图标，不弹独立窗口。

## 7. 信息架构与布局 🔶

```
┌──────────────────────────────────────────────────────────┐
│ 侧栏 260px                    │  主区                      │
│ ┌──────────────────────────┐  │  工具栏: 面包屑 · 搜索 ·   │
│ │ [Logo]        [⌘K] [+集群]│  │  上传 ▾ · 刷新 · 更多     │
│ ├──────────────────────────┤  │ ┌──────────────────────┐ │
│ │ ▉ prod-minio      ● 已连 │  │ │ 对象表格 / 桶表格     │ │
│ │   └ 桶列表(可折叠)        │  │ │                      │ │
│ │ ▉ dev-minio       ○ 未连 │  │ │                      │ │
│ │ ▉ aws-cn        ● 已连   │  │ └──────────────────────┘ │
│ ├──────────────────────────┤  │  底部: 传输条(可展开)      │
│ │ 传输 · 同步 · 日志 · 设置  │  │                          │
│ └──────────────────────────┘  │                          │
└──────────────────────────────────────────────────────────┘
```

- **侧栏**：集群分组列表，每项左侧 4px 集群色条（`--cluster-*`）+ 连接状态点；当前集群整行品牌 wash 洗底。可折叠为 56px 图标窄栏 ✅（继承 chat 侧栏折叠交互）。
- **⌘K 命令面板**：切集群、切桶、跳前缀、执行动作（上传/生成预签名/删除）；研发键盘流的核心入口。
- **底部传输条**：常驻细条显示「3 个任务进行中 · 12.4 MB/s」，点击展开抽屉，抽屉内为任务列表 + 每任务可展开流式日志。
- **路径导航**：面包屑（桶 / dir / subdir）+ 「复制 s3:// URI」ghost 按钮；key 名称一律 mono。
- **对象详情**：右侧滑入面板（16px 圆角）：元数据（ETag、Size、StorageClass、VersionId、LastModified、Checksum、SSE）+ 标签 + 版本历史 + 预签名生成卡（方法/有效期/复制链接）。

## 8. 关键交互流程

1. **首次启动**：空画布居中白卡「连接你的第一个集群」→ 表单（endpoint/region/AK/SK/path-style/自签证书开关）→「测试连接」（HeadBucket 探活 + 延迟）→ 成功后进入主界面。
2. **集群切换**：侧栏点击 / ⌘K / Ctrl+1..9；切换即整树刷新，顶部 4px 色条同步变色——**一眼确认当前在哪个集群，防误操作 prod**。
3. **危险操作**：删除桶/批量删除对象 → 对话框完整列出「集群 prod-minio · bucket logs · 1,204 个对象」+ 需输入桶名确认（prod 集群强制）。
4. **错误呈现**：任何失败 → toast（Code + Message）+ 详情展开（RequestId、x-amz-id-2、原始响应）+ 一键复制；`PermanentRedirect/TemporaryRedirect` 时额外提示「该桶位于 xxx，是否切换 endpoint？」。
5. **能力探测降级**：对 MinIO 隐藏 ACL/Website 入口；不支持的配置 tab 显示灰态 chip「该集群不支持（MinIO）」。
6. **深浅色**：跟随系统 + 手动切换（设置页）；所有 token 双套实现，无硬编码色。

## 9. 相对 DeepSeek 原作的本产品特化

| 特化点 | 理由 |
| --- | --- |
| 2px 品牌蓝 focus ring | 原作未自定义，研发键盘流需要 |
| mono 字体通道 | key/ETag/endpoint/错误码是核心信息 |
| 表格密度档位（舒适 36px / 紧凑 28px） | 研发浏览大桶列表 |
| 集群标识色条系统 | 多集群防误操作的核心视觉机制 |
| 传输流式日志折叠区 | 继承「深度思考」隐喻，服务传输可观测 |
